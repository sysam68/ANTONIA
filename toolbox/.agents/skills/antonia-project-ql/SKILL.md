# Derive the OWL 2 QL projection

Read the repository-root `AGENTS.md`, `config/config.env`, and the configured QL
update. From the repository root, run:

```bash
make project-ql
```

Keep the derived QL projection distinct from the expressive OWL 2 DL reference
ontology and report the generated path.
